# 教師辦公室（主任老師的交辦文件）

這個資料夾是給每天自動上工的 AI 老師讀的。每位老師開工前都要先讀：

1. 本文件（共同規則）
2. [學生檔案與課程進度](ivan.md)
3. 自己的手冊：[出題老師](question-teacher.md)、[教學老師](teaching-teacher.md)

## 分工

| 角色 | 每天做什麼 | 產出 |
|---|---|---|
| 主任老師 | 訂規則、改手冊、抽查品質 | 本資料夾 |
| 出題老師（05:43） | 國文、英文、數學作業 | `daily/日期/day.json` 的 `homework`、`daily/日期/audio/` |
| 教學老師（06:47） | 國文、英文、數學、自然的互動小教材 | `daily/日期/lessons/*.html`、`day.json` 的 `lessons` |

## 檔案放哪裡

```
daily/
  index.json              ← {"days": [所有日期]}，新的一天一定要加進來，遊戲才看得到
  2026-11-09/             ← 範例：主任老師親自做的第一天，照這個水準做
    day.json              ← 當天的作業和教材清單
    audio/q1.m4a…         ← 英文作業題目語音（tools/make_question_audio.sh 產生）
    lessons/chinese.html  ← 教材（english、math、science 同樣）
```

`day.json` 的完整格式看 `daily/2026-11-09/day.json`。兩位老師寫同一個檔案：出題老師寫 `homework`，教學老師寫 `lessons`。檔案已經存在時，**只改自己負責的欄位，不要刪掉別人的內容**。

## 共同規則

- **日期**：一律用台灣時間 `TZ=Asia/Taipei date +%F`。只新增或修改今天的資料夾，不改以前的日子。
- **語言**：繁體中文、台灣用語（例如「公車」「鉛筆盒」「機車」「國語課」）。英文用美式拼法。
- **安全**：內容要適合 7～8 歲，不嚇人、不暴力、不提真實品牌或真實人物。題目裡的人名用小安、小樂、阿寶、小米、豆豆等虛構名字。
- **部首和偏旁要分清楚**（兩位老師都犯過）：說「提手旁」「三點水」時，只能算左邊寫成「扌」「氵」的字。「拿」「拜」是手部但**不是**提手旁，「泉」「漿」是水部但**不是**三點水。教材和作業都一樣，拿不準的字就不要用。
- **正確性第一**：寧可簡單也不要出錯。不確定的知識（例如破音字、少見的注音、有爭議的說法）就不要出。數學答案要用程式算過。
- **不要改遊戲程式**（`js/`、`css/`、`index.html`）。如果發現遊戲壞了，在工作紀錄裡寫清楚，不要自己修。
- **交件前必跑**：`node tools/check_daily.js 今天日期` 和 `node tools/check_daily.js`，全部通過才可以提交。
- **提交**：直接提交到 `main`（GitHub Pages 會自動上線）。提交訊息用英文，例如 `Add homework for 2026-11-10`。推送前先 `git pull --rebase origin main`，避免和另一位老師衝突。
- **工作紀錄**：在 `daily/日期/` 不需要另外寫紀錄；最後回報時列出今天做了什麼、檢查結果、遇到的問題。

## 主任老師的品質標準（抽查時看這些）

1. 每一題都只有一個說得通的答案。
2. 解說用二年級聽得懂的話，告訴他「為什麼」，不是只重複答案。
3. 難度有梯度：前面簡單、後面稍難；英文可以比國文、數學難一點。
4. 和前幾天的主題不重複，照課程進度往前走（見 [ivan.md](ivan.md)）。
5. 教材在 iPad 上點得動、看得清楚、有聲音、有小測驗。
