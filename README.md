# 學習大冒險 🏝️

for Ivan 🧒

給 Ivan 玩的地圖冒險學習遊戲，主角是戴頭盔、拿劍和盾的「Ivan勇士」。一開始先選國度，每個國度都被魔王占領了：打敗每一區的三隻手下和魔王，就能拿回寶物，最後到城堡打大魔王。所有地區、關卡和最終城堡一開始就全部開放，想玩哪一關就玩哪一關。

每一題都是一次戰鬥：答對就使出這一區的招式打怪物，連續答對 3 題放必殺技；答錯時怪物會反擊，接著顯示解說。

## 📝 今日作業（英文口說）

英文地圖最下面、首頁上方都有「今日作業」。每一題先聽問題、自己回答，答案預設藏起來，按「👀 看答案」才會顯示示範的完整句子（可以聽、🐢 慢慢念、點選自己的答案）。

🎤 錄音會自動保存在這台 iPad 上，每題都能重聽、按「📤 傳給老師／存檔」用 LINE、AirDrop 分享或存到「檔案」。完成頁有「🎧 我的錄音」清單，可以一次傳送全部錄音，也可以按「🔗 合併成一個檔案」把每題的錄音照順序接成一個 WAV 檔（每題中間留一點空白），在 iPad 上就能完成。

最後一步「📖 10 題全部念一次」：同一頁列出 10 題題目和 Ivan 選的答案，可以先聽一遍示範，再從 Q1 念到 Q10 錄成一個檔案（`Ivan-日期-all`），一樣能分享給老師。

老師出新作業時，只要改 `js/homework.js`：換掉日期和題目就好（檔案最上面有說明）。

## 特色

- 題目由程式隨機組合，可以一直重玩。
- 答錯時會顯示正確答案和解說。
- 🔊 念題目：國文、數學用中文語音，英文題用英文語音；英文還有聽力題。
- 進度存在這台裝置的瀏覽器裡，不需要帳號。
- ⚙️ 家長設定（要先答一題乘法）：看三科各地區的答對率、調整每隻手下的血量（題數）、自動念題目和劇情、重新播放劇情、清除進度。

## 怎麼玩

直接用瀏覽器打開 `index.html` 就能玩。放上 GitHub Pages 之後，用 iPad／手機打開網址，按「分享 → 加入主畫面」，就會像 App 一樣。

## 檔案

- `index.html`：頁面
- `css/style.css`：畫面樣式
- `js/questions.js`：數學題目產生器
- `js/chinese.js`：國文題庫和題目產生器
- `js/english.js`：英文題庫和題目產生器
- `js/story.js`：數學的劇情、怪物、招式
- `js/subjects.js`：三個國度的設定，以及國文、英文的劇情
- `js/homework.js`：今日作業的題目（換作業改這裡）
- `js/game.js`：選擇國度、地圖、戰鬥、今日作業、存檔、家長設定
