# 數字島大冒險 🏝️

for Ivan 🧒

給小學 2～4 年級的數學地圖冒險遊戲。走遍 9 個地區、每區 3 關加 1 個魔王，打敗魔王就能拿到寶物，並開放下一個地區。

| 地區 | 年級 | 內容 |
|---|---|---|
| 🌼 加減草原 | 二 | 兩位數加減、進位和退位、三位數加減 |
| 🌳 乘法森林 | 二 | 九九乘法、乘法應用題 |
| ⏰ 時鐘山谷 | 二 | 整點和半點、幾時幾分、經過多久 |
| 🪙 錢幣市集 | 二 | 數錢幣、找錢 |
| 🪨 除法洞窟 | 三 | 平分、有餘數的除法、應用題 |
| 🐚 分數海灣 | 三 | 認識分數、比大小、同分母加減 |
| 📏 測量高原 | 三 | 公尺／公分、公斤／公克、公升／毫升、周長 |
| 🌋 大數火山 | 四 | 萬位、多位數乘法、兩位數乘法和除法 |
| 🌙 小數星空 | 四 | 認識小數、比大小、小數加減 |

## 特色

- 題目每次都由程式隨機產生，不會一直重複。
- 答錯時會顯示正確答案和解說（直式、口訣、拆數字）。
- 🔊 按鈕可以念題目給還在認字的小孩聽。
- 進度存在這台裝置的瀏覽器裡，不需要帳號、不需要網路後端。
- ⚙️ 家長設定（要先答一題乘法）：看各地區答對率、開放全部關卡、調整每關題數、自動念題目、清除進度。

## 怎麼玩

直接用瀏覽器打開 `index.html` 就能玩。放上 GitHub Pages 之後，用 iPad／手機打開網址，按「分享 → 加入主畫面」，就會像 App 一樣。

## 檔案

- `index.html`：頁面
- `css/style.css`：畫面樣式
- `js/questions.js`：9 個地區的題目產生器（要改題目、加題型都在這裡）
- `js/game.js`：地圖、關卡、魔王戰、存檔、家長設定
