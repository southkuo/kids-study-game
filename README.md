# 學習大冒險 🏝️

for Ivan 🧒

給 Ivan 玩的地圖冒險學習遊戲，主角是戴頭盔、拿劍和盾的「Ivan勇士」。一開始先選國度，每個國度都被魔王占領了：打敗每一區的三隻手下和魔王，就能拿回寶物，最後到城堡打大魔王。所有地區、關卡和最終城堡一開始就全部開放，想玩哪一關就玩哪一關。

每一題都是一次戰鬥：答對就使出這一區的招式打怪物，連續答對 3 題放必殺技；答錯時怪物會反擊，接著顯示解說。

## 📅 今日任務（每天自動更新）

首頁最上面是「今日任務」，每天由兩位 AI 老師自動準備（規則在 `teachers/`）：

- **出題老師**（每天早上）：英文口說作業 5 題（照學校老師的風格，可錄音、合併、傳給老師）、國文作業、數學作業（各約 8 題，用戰鬥的方式作答，答錯的題目會再出一次）。
- **教學老師**（每天早上）：國文、英文、數學、自然各一份互動小教材（「📚 今日教室」）。
- 按「📆 以前的」可以回去練習以前的任務。
- 首頁只顯示今日任務；「選擇國度」自由冒險關卡預設隱藏，可以在 ⚙️ 家長設定打開。

每天的內容放在 `daily/日期/`：`day.json`（作業和教材清單）、`audio/`（英文題目語音）、`lessons/`（教材）。交件前用 `node tools/check_daily.js` 檢查。

### 英文口說作業的功能

每一題先聽問題、自己回答，答案預設藏起來，按「👀 看答案」才顯示示範句子（可以聽、🐢 慢慢念、點選自己的答案）。🎤 錄音自動保存在 iPad 上，可以分享給老師；完成後可以「🔗 合併成一個檔案」（每題先念題目、再接 Ivan 的回答），或到「📖 全部念一次」把 10 題從頭念到尾錄成一個檔案。

## 特色

- 題目由程式隨機組合，可以一直重玩。
- 答錯時會顯示正確答案和解說。
- 🔊 念題目：國文、數學用中文語音，英文題用英文語音；英文還有聽力題。
- 進度存在這台裝置的瀏覽器裡，不需要帳號。
- ⚙️ 家長設定（要先答一題乘法）：看三科各地區的答對率、調整每隻手下的血量（題數）、自動念題目和劇情、重新播放劇情、清除進度。

## 怎麼玩

直接用瀏覽器打開 `index.html` 就能玩。放上 GitHub Pages 之後，用 iPad／手機打開網址，按「分享 → 加入主畫面」，就會像 App 一樣。

## 檔案

- `index.html`：頁面
- `css/style.css`：畫面樣式
- `js/questions.js`：數學題目產生器
- `js/chinese.js`：國文題庫和題目產生器
- `js/english.js`：英文題庫和題目產生器
- `js/story.js`：數學的劇情、怪物、招式
- `js/subjects.js`：三個國度的設定，以及國文、英文的劇情
- `js/game.js`：今日任務、選擇國度、地圖、戰鬥、作業、教材、存檔、家長設定
- `daily/`：每天的作業和教材；`teachers/`：AI 老師的手冊；`tools/`：檢查工具和語音產生器
